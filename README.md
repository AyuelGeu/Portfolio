# Ayuel Geu — Portfolio (plain HTML)

No build step, no install. Five linked pages, one shared stylesheet.

## Use it

Open `index.html` directly in a browser, or drop the whole folder onto any
static host (GitHub Pages, Netlify, Vercel, etc.) — it works as-is.

## Files

- `index.html` — Home
- `about.html` — About
- `projects.html` — Projects
- `blog.html` — Blog
- `contact.html` — Contact
- `styles.css` — all styling and design tokens (colors, type, layout)

## What to customize first

1. Each page's placeholder text — search for "Placeholder" across the files
2. Project cards in `projects.html` and the featured one in `index.html`
3. Blog entries in `blog.html`
4. Email/GitHub/LinkedIn links — appear in the footer of every page and on `contact.html`
5. The contact form in `contact.html` doesn't send anywhere yet — point its `action` at a
   service like Formspree, or wire it to a small backend, when you're ready
